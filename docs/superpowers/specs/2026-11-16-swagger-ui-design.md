# Swagger UI 설정

프론트가 현재 서버 API를 조회하고 JWT로 호출할 수 있도록 Spring Boot 4.1과 호환되는 springdoc-openapi 3.2.0 Web MVC UI를 붙인다. 별도 문서 서버 대신 같은 서버의 `/swagger-ui/index.html`과 `/v3/api-docs`를 사용한다. 구현은 최신 main에서 독립 브랜치로 진행하고 배포는 하지 않는다.

문서 경로만 익명 조회를 허용한다. 기존 API 인증·인가 정책은 유지한다. OpenAPI는 `/api/v1/**`만 노출하고 bearer JWT 방식을 등록한다. 가입·로그인은 인증 불필요로 명시한다. 토큰을 브라우저 재시작 후 보관하지 않는다. 외부 Swagger Petstore 기본 문서와 외부 validator를 사용하지 않는다.

상대 서버 주소로 실행한 서버에 요청하며 배포 주소를 임의 지정하지 않는다. 노션의 정책 설명·수동 JSON 바인딩의 세부 계약을 자동 생성 문서가 모두 대체하지는 않는다. 이번 범위는 공통 설정이며 API별 상세 주석 전면 작성, 기능 변경, 배포·외부 전송은 포함하지 않는다.

접근 방식: 기존 컨트롤러 기반 springdoc 자동 생성을 선택했다. 별도 정적 OpenAPI 수기 작성은 계약이 중복되어 유지보수 부담이 있고 별도 문서 호스팅은 필요하지 않다. 인증 스키마와 공개 인증 API 표시 외 DTO·컨트롤러 동작은 바꾸지 않는다.
